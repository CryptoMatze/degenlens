Privacy Policy

DegenLens by CryptoMatze — Chrome Extension
Last updated: 2026-10-29
Short version: DegenLens does not collect, store, or transmit any personal data about you to its own servers. All processing happens locally in your browser. The extension queries public third-party APIs (DexScreener, RugCheck, GoPlus, Pump.fun) for token data, and includes referral codes on outbound trade links to Photon.

1. What DegenLens Does

DegenLens is an informational tool that injects a side panel into supported websites (DexScreener, Pump.fun, Photon and — only if you switch them on — GMGN, Axiom, Birdeye and X) to display on-chain risk intelligence about Solana memecoins — including liquidity, holder concentration, security checks, and bonding curve status. It is provided as-is for informational purposes only and is not financial advice.

2. Data We Do Not Collect

DegenLens does not:

  • Collect personally identifiable information (PII)
  • Track your browsing history outside the supported sites
  • Access your wallet, private keys, seed phrases, or trading activity
  • Send any analytics, telemetry, or usage data to first-party servers
  • Store any data on external servers (the extension has no backend)
  • Sell or share data with third parties

3. Data Stored Locally on Your Device

DegenLens uses Chrome's chrome.storage.sync API to persist a small set of user preferences across your signed-in Chrome browsers:

  • autoOpen — whether the analysis panel opens automatically on supported sites
  • showSignals — whether the narrative signal section is shown
  • simSol and collapsed — the trade-simulator amount and which panel sections you collapsed
  • lang, dock, compact, tabY — language, panel side, compact view and the position of the side tab
  • alerts, alertMovePct, extraSites — whether watchlist alerts and the optional sites are switched on

In addition, chrome.storage.local keeps your scan history (last 40 tokens you viewed: token address, symbol, name, score, price, time) and your watchlist on this device only, so the toolbar popup can show them. You can remove watchlist entries at any time; uninstalling the extension deletes all of it. If you switch on watchlist alerts, chrome.storage.local also keeps the last checked price and liquidity per watchlist token, so a change can be detected.

This data never leaves your browser / Google account's sync mechanism. We have no access to it.

4. Third-Party APIs We Query

When you open a token page on a supported site, DegenLens sends the token's on-chain address to the following public third-party APIs to fetch market and security data:

  • DexScreener API (api.dexscreener.com) — token price, liquidity, volume, transactions, social links, boost status
  • RugCheck API (api.rugcheck.xyz) — mint/freeze authority, LP status, insider networks, risk score (Solana only)
  • GoPlus Security API (api.gopluslabs.io) — honeypot detection, ownership status, holder count, tax checks
  • Pump.fun frontend API (frontend-api-v3.pump.fun) — community replies, description, NSFW flag (Pump.fun tokens only)
  • Public Solana RPC nodes (api.mainnet-beta.solana.com, solana-rpc.publicnode.com) — the token's public pump.fun bonding-curve account (curve progress, fees, creator)

These APIs receive only the public token address. They are public services with their own privacy policies. The requests are made directly from your browser (the extension's background worker) to these services — DegenLens has no server and does not proxy or log them.

Watchlist alerts (optional, off by default)

If you switch on watchlist alerts in the popup, the extension asks for the notifications permission. Every 3 minutes while Chrome is running it sends the public addresses of your watchlist tokens (up to 30) to the DexScreener API and shows a local desktop notification on a liquidity pull or a large price move. Nothing else is sent, and the check stops when you switch alerts off.

Optional sites (off by default)

If you switch on "More sites", the extension asks for access to gmgn.ai, axiom.trade, birdeye.so, x.com and twitter.com. On the token pages of the first three it shows the same panel. On X it only reads the text of posts on the page you are viewing to find Solana contract addresses and adds a "Scan" button next to them. Nothing is read or sent until you click that button; then only the public token address goes to the APIs listed above. You can withdraw this access at any time in the popup or in chrome://extensions.

Feedback and uninstall survey (voluntary)

The "Score looks wrong?" link in the panel and the page that opens after uninstalling are hosted on GitHub Pages (cryptomatze.github.io/degenlens). Nothing is sent unless you press "Send". Then the page transmits only your chosen answer, your optional text, the extension version, and on the score page the token address and score, to the developer as a push message via ntfy.sh. No IDs, cookies or tracking are involved.

6. Permissions Used

DegenLens requests the following Chrome extension permissions:

  • activeTab — to detect which token page you are on (required to fetch its data)
  • storage — to remember your settings between sessions (see Section 3)
  • alarms — to schedule the watchlist check (only runs if you switch alerts on)
  • scripting — to add the panel to the optional sites after you grant them
  • Host permissions for the supported sites and APIs listed above — required to inject the panel and fetch data
  • Optional, requested only when you switch them on: notifications (watchlist alerts) and access to gmgn.ai, axiom.trade, birdeye.so, x.com, twitter.com (more sites)

The extension does not request any other browser permissions.

7. Cookies

DegenLens does not set or read any cookies of its own. The third-party sites (DexScreener, Pump.fun, Photon) and APIs may set their own cookies as part of their normal operation — these are governed by their respective privacy policies.
